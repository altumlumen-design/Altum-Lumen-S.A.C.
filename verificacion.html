Verificación de documentos emitidos

Este es el punto oficial de consulta para comprobar la autenticidad y el estado de documentos emitidos por ALTUM LUMEN S.A.C. mediante un código de verificación o el QR incorporado en el documento.

Ruta oficial permanente del Portal Corporativo

Consultar un documento

Ingrese el código de verificación consignado en el documento. En las próximas versiones, el QR podrá abrir esta página con el código cargado automáticamente.

Módulo en integración con el SGD La ruta pública ya se encuentra definida para ser utilizada en los modelos institucionales. La consulta automática de registros será habilitada cuando se conecte este portal con el Sistema de Gestión Documental.

Importante

La presencia de un QR que dirija a esta página identifica la ruta institucional de verificación. La validación definitiva del contenido, estado, emisor y firma se realizará contra el registro del SGD una vez culminada la integración.

¿Cómo funcionará?

La página ha sido preparada para mantener una sola dirección web aun cuando se amplíen las funcionalidades de verificación.

  1. 1Escanee el QR o ingrese el código consignado en el documento.
  2. 2El portal consultará el registro institucional asociado al documento.
  3. 3Se mostrará su estado, datos de emisión y elementos de validación autorizados.
